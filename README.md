# victoriafloresdev.github.io

Personal site of **Victoria Flores Mello**, AI/ML Engineer & Researcher.

Live at **https://victoriafloresdev.github.io**

- `/` · `/work` · `/research` · `/about`: the portfolio
- `/play`: an optional pixel-art village to explore the same content as a tiny game

Built with [Astro](https://astro.build) and vanilla canvas, and deployed to GitHub Pages from the `gh-pages` branch.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm run deploy   # build and publish to GitHub Pages
```
